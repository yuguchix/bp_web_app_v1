# 血圧記録WEBアプリ v3

GitHub Pages 上で `Blood_Pressuer.xlsx` を読み込み、`記録` シートの既存データを表とグラフで表示する確認版です。

## 今回の修正点

`Blood_Pressuer.xlsx` の実レイアウトに合わせて、以下の固定セル位置から読み込むように修正しました。

- データ開始: `B3`
- `B列`: 日付
- `C列`: 朝の時間
- `D列`: 朝の最高血圧
- `E列`: 朝の最低血圧
- `F列`: 朝の心拍数
- `G列`: 夜の時間
- `H列`: 夜の最高血圧
- `I列`: 夜の最低血圧
- `J列`: 夜の心拍数

B25 のように夜の値が未入力の場合は、朝の記録だけを表示します。

## ファイル配置

GitHub Pages の公開対象フォルダに、次のファイルを同じ階層で置いてください。

```text
index.html
style.css
app.js
Blood_Pressuer.xlsx
```

ファイル名は完全一致が必要です。

```text
Blood_Pressuer.xlsx
```

## 確認ポイント

ページを開くと、ステータスに次のような表示が出ます。

```text
45件を読み込みました（B3開始 / 最終行B25 / 2026-05-25 〜 2026-06-16）
```

2026/5/25 から 2026/6/16 朝まで読み込めていれば成功です。

## 注意

この版の入力ボタンは、画面上に一時追加するだけです。GitHub Pages は静的サイトなので、ブラウザから直接 `Blood_Pressuer.xlsx` を上書き保存することはできません。

次の段階で、保存方法を以下のどれかに決めます。

1. スマホ内のブラウザ保存（localStorage）
2. 入力データをCSV/Excelとしてダウンロード
3. GitHub APIでリポジトリ内のExcel/JSONを更新
4. GoogleスプレッドシートをDB代わりに使う
